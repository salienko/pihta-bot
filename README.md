# pihta-bot

Telegram-бот семейной бани «Пихта» на aiogram 3.

Команда `/start` открывает меню «О бане», «Забронировать»,
«Связаться с нами». Ответы содержат ссылки на https://banyapihta.ru/.
Бронирование и контакты доступны на сайте; бот не подтверждает бронирования.

## Запуск

1. Используйте Python 3.11.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Задайте `BOT_TOKEN` в переменных окружения хостинга.
4. Запустите `python bot.py`.

## Bothost

- Платформа: Telegram.
- Среда: Python 3.11.
- Регион: Нидерланды.
- Репозиторий: `https://github.com/salienko/pihta-bot`.
- Ветка: `main`.
- Команда запуска: `python bot.py`.
- Зависимости: `requirements.txt`.
- Секретная переменная окружения: `BOT_TOKEN`.

Работает через long polling: нужен один запущенный экземпляр на токен.
При запуске бот проверяет токен, отключает webhook без удаления ожидающих
сообщений и регистрирует команду `/start`.

Если токен был раскрыт, отзовите его через BotFather `/revoke` и введите
новый непосредственно в защищённое поле Bothost. Не отправляйте токен
в чат, не сохраняйте его в коде и не коммитьте в репозиторий.

После развёртывания проверьте в Telegram `/start`, все три пункта меню
и переходы на сайт. Успешная сборка сама по себе не подтверждает работу бота.
